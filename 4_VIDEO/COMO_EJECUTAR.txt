## 🎯 Descripción

Sistema OCR End-to-End basado en arquitectura CRNN (Convolutional Recurrent Neural Network) con capacidad dual:

- **Texto Impreso:** 93.97% precisión (dataset sintético)
- **Texto Manuscrito:** 89.95% precisión (Transfer Learning desde impreso)

### Características Principales

✅ Arquitectura estado del arte (CRNN + CTC Loss)
✅ Transfer Learning validado empíricamente
✅ Interfaz web interactiva (Gradio)
✅ Soporte para español (acentos, ñ)
✅ Sin dependencias de OCR externos (Tesseract, etc.)

---

## 📊 Rendimiento

### Modelo Texto Impreso
- **Test CER:** 0.0603 (93.97% precisión)
- **Test Accuracy:** 80.78% (palabras exactas)
- **Dataset:** 100,000 imágenes sintéticas
- **Tiempo entrenamiento:** 8 horas (GPU T4)

### Modelo Texto Manuscrito
- **Test CER:** 0.1005 (89.95% precisión)
- **Test Accuracy:** 74.24% (palabras exactas)
- **Dataset:** 96,456 palabras (IAM Database)
- **Estrategia:** Transfer Learning + Fine-tuning
- **Tiempo entrenamiento:** 6.5 horas (GPU T4)

### Comparativa Transfer Learning
| Método | Precisión | Tiempo |
|--------|-----------|--------|
| **Con Transfer Learning** | **89.95%** | 6.5h |
| Desde cero (Kaggle) | 82.51% | 6.5h |
| **Mejora** | **+7.44 pp** | - |

- Python 3.8+
- 8GB RAM mínimo


## 🎓 Conceptos Clave Implementados

1. **Transfer Learning:** Reutilización de conocimiento impreso → manuscrito
2. **Fine-tuning progresivo:** CNN freeze → unfreeze
3. **Data Augmentation:** Rotación, blur, noise, perspectiva
4. **CTC Loss:** Alineación automática sin segmentación
5. **BiLSTM:** Contexto bidireccional en secuencias
6. **Early Stopping:** Prevención de overfitting
7. **OneCycleLR:** Optimización de learning rate

## 🚧 Limitaciones Conocidas

1. **Caracteres no-inglés:** Dataset IAM es inglés, confunde ñ→ri
2. **Cursiva extrema:** Palabras muy largas con cursiva unida
3. **Contexto semántico:** No usa modelo de lenguaje para corrección
4. **Segmentación:** Requiere 1 línea/palabra por imagen

---

## 🔮 Mejoras Futuras

1. **Language Model:** N-gramas o Transformer para corrección ortográfica
2. **Page Segmentation:** Detectar líneas automáticamente (YOLO/Faster R-CNN)
3. **Dataset español:** Entrenar con texto manuscrito español nativo
4. **Quantization:** Reducir modelo para móviles (32-bit → 8-bit)
5. **Beam Search:** Mejorar decodificación CTC

📏 REQUISITOS DE IMAGEN
─────────────────────────────────────────────────────────────────────

✅ FORMATOS SOPORTADOS
   • JPG / JPEG
   • PNG
   • BMP
   • TIFF

✅ CARACTERÍSTICAS ÓPTIMAS
   • Fondo claro (blanco/gris claro)
   • Texto horizontal (máx ±5° inclinación)
   • Alto contraste texto-fondo
   • Una línea de texto por imagen
   • Resolución mínima: 300 DPI recomendado
   • Tamaño texto: 12-48pt

❌ EVITAR
   • Fondos muy texturizados
   • Texto muy inclinado (>10°)
   • Múltiples líneas (funciona pero menos preciso)
   • Imágenes muy borrosas
   • Muy baja resolución (<200 DPI)
